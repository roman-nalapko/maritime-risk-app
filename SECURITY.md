# Security and privacy

## Current architecture

The prototype is static and sends no questionnaire data to a backend. There are no accounts, cookies, analytics, or runtime secrets.

## Reporting

Open a private security advisory in the repository for vulnerabilities. Do not include real personal or incident data in a public issue.

## Future changes requiring review

- cloud storage or synchronization;
- authentication or organization accounts;
- analytics or session replay;
- third-party AI/API calls;
- uploads of incident reports;
- decisions affecting employment, health, insurance, or duty status.
