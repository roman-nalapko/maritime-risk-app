# Contributing

Read `AGENTS.md`, `docs/product-spec.md`, and `docs/risk-model.md` before changing behavior.

1. Create a focused branch.
2. Keep calculations pure and coefficient metadata explicit.
3. Run `npm test` and `npm run build`.
4. Explain any methodology change in `docs/decisions.md`.
5. In the pull request, distinguish UI changes, code changes, and domain assumptions.

Do not submit personal incident records, confidential investigation material, or unlicensed source data.
