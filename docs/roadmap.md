# Roadmap

## Phase 0 — hypothesis prototype (included)

- Browser-only questionnaire and deterministic result.
- Explainable components and rule-based recommendations.
- Synthetic incident explorer.
- Responsive PWA shell and documentation.

## Phase 1 — methodology review

- Review outcomes, formulas, and coefficients with the instructor.
- Correct disputed source-table values.
- Define maritime roles, operations, and exposure units.
- Freeze model version `1.0` and add calculation fixtures.

## Phase 2 — real data

- Build MAIB CSV import and validation.
- Map external taxonomies to the internal schema.
- Add provenance, reporting-period, and sample-size labels.
- Introduce confidence intervals and sparse-sample warnings.

## Phase 3 — research pilot

- Usability testing with cadets/workers and a safety specialist.
- Accessibility audit and bilingual terminology review.
- Compare model output with historical scenarios.
- Document limitations and governance.

## Phase 4 — optional AI

- Classify narrative reports into reviewed causal tags.
- Retrieve similar investigated incidents.
- Draft explanations grounded in cited reports.
- Keep numeric computation outside the language model.

## Phase 5 — operational consideration

Only after formal validation: authentication, organization-level dashboards, audit logs, controlled data retention, privacy/legal review, and certified deployment controls.
