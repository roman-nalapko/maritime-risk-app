# Design system

## Direction

“Instrument panel, not alarm panel.” The interface uses deep navy, calm cyan, sea-glass surfaces, and warm amber only for attention. It should feel credible and technical without resembling a medical diagnosis or emergency console.

## Tokens

- Background: `#071521`
- Raised surface: `#0D2232`
- Primary surface: `#F5F8FA`
- Ink: `#102536`
- Muted: `#617786`
- Cyan: `#22C7B8`
- Blue: `#5FA8FF`
- Amber: `#F1B24A`
- Coral: `#E96B61`
- Radius: 16–24 px for cards, 12 px for controls
- Type: system sans-serif for speed and broad Cyrillic coverage

## Layout

- 12-column desktop grid with questionnaire and result in a 5/7 split.
- Single-column mobile layout with the result immediately after the form.
- Maximum content width: 1180 px.
- Touch target minimum: 44 px.

## Data presentation

- A number is always paired with its unit and semantic label.
- Color never carries meaning alone; every state has text or an icon.
- Percentages distinguish annual estimate, component share, and incident share.
- Bars begin at zero. Avoid decorative 3D charts and gauges without a readable numeric value.

## Voice

Direct, calm, and conditional. Prefer “розрахункова оцінка” over “ваш шанс загинути.” Recommendations describe controllable factors and never blame the worker.
